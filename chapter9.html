Chapter 9

내장 객체
- 사용자가 가져다 쓸 수 있도록 미리 만들어진 객체
- 웹 브라우저에 웹 문서가 열리면 가장 먼저 window 객체가 만들어지고 하위에 웹 브라우저 요소에 해당하는 객체들이 만들어진다.

최상위 객체, window
- window 객체는 웹 브라우저 창의 상태를 제어하는 객체
- 자바스크립트의 모든 객체는 window 객체에 포함된다
- 웹 브라우저 창과 관련된 여러가지 속성이 있다. ( document, frameElement, innerHeight, innerWidth, localStorage )
- 속성과 매서드에 접근하는 마침표를 사용한다.
팝업창을 여는 open() 함수
브라우저 창을 닫는 close() 함수
screen 객체 : 사용자의 화면 크기나 방향 등의 정보를 담고 있는 객체
history 객체 : 브라우저에서 [뒤로] 나 [앞으로] 또는 주소 표시줄에 입력해서 방문한 사이트 주소가 배열 형태로 저장됨, 보안 문제 때문에 읽기 전용
location 객체 : 현재 문서의 URL 주소와 관련된 정보가 들어있음
Date 객체 : 날짜와 시간에 대한 정보를 조절할 수 있는 객체
Math 객체 : 삼각 함수나 로그 함수를 비롯한 수학 연산 함수를 가지고 있는 내장 객체
