chapter 4 summary

입력과 출력 방법
- alert()함수 : 알림 창 표시
- confirm()함수 : 확인 창 표시
- prompt()함수 : 사용자가 간단한 값을 입력할 수 있는 창 표시
- console.log()함수 : 콘솔 창에 괄호 안의 내용 표시
- document.write()함수 : 괄호 안의 내용을 웹 브라우저 화면에 표시

변수 : 프로그램에서 사용하기 위해 값을 담아놓는 바구니
변수 이름 정하는 규칙
1. 변수 이름은 숫자로 시작할 수 없고 이름 안에 공백이 포함되어 있으면 안됨
2. 자바스크립트는 영문자의 대소문자를 구별
3. 한 단어로 이루어진 변수를 사용할 때에는 주로 소문자 사용
4. 두 단어 이상으로 이루어진 변수는 언더바(_)로 연결하거나 중간에 대문자 섞어 사용
5. 자바스크립트에서 미리 정해 놓은 예약어(ex : let)는 변수 이름으로 사용할 수 없음
6. 무의미한 변수 이름은 피한다

변수 선언 및 할당
1. 변수 선언 : let 변수명;(재선언 불가능, 재할당 가능) const 변수명;(재선언, 재할당 불가능) (var 변수는 재선언, 재할당 가능 자바스크립트 역할 커지면서 var로는 부족해짐)
2. 변수에 값 할당 : 변수명 = 값 또는 식;
3. 변수 선언과 값 할당을 동시에 할 수도 있다 : let 변수명 = 값 또는 식;

자료형(data type) : 프로그램에서 처리하는 자료의 형태
- 원시형 : 하나의 값만 가지고 있는 자료형
- 객체 : 원시형 외의 모든 자료
- 기본형 : number, string, boolean, undefined, null
- 복합형 : null, array, object
- typeof()함수 : 괄호 안에 값이나 변수 넣으면 어떤 자료형인지 알려준다
- 배열 : 하나의 변수에 여러 값을 할당할 수 있는 형태, []로 묶고, 그 안에 값 나열
인덱스 : 배열에 있는 여러 값을 저장하는 방 번호 (0부터 시작)
자료형 변환

- 숫자형으로 변환 : Number(), parseInt() 정수로 변환, parseFloat() 실수로 변환
- 문자열로 변환 : toString(), String()
- 논리형으로 변환 : Boolean()
