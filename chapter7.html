event 객체 : 이벤트가 발생하면 자동으로 만들어지는 객체
event 객체의 매서드
- preventDefault : 기본 동작을 취소합니다.
event 객체의 프로퍼티
- altKey : 이벤트가 발생했을 때 Alt를 누르고 있었는지의 여부를 확인하고 Boolean 값을 반환
- button : 마우스 키 반환
- charCode : keypress 이벤트가 발생했을 때 어떤 키가 눌렸는지 유니코드값으로 반환
- clientX : 이벤트가 발생한 가로 위치 반환
- clientY : 이벤트가 발생한 세로 위치 반환
- ctrlKey : 이벤트가 발생했을 때 ctrl를 누르고 있었는지의 여부 확인하고 Boolean 값을 반환
- pageX : 현재 문서를 기준으로 이벤트가 발생한 가로 위치 반환
- pageY : 현재 문서를 기준으로 이벤트가 발생한 세로 위치 반환
- screenX : 현재 화면 기준으로 이벤트가 발생한 가로 위치 반환
- screenY : 현재 화면 기준으로 이벤트가 발생한 세로 위치 반환
- shiftKey : 이벤트 발생했을 때 shift 를 누르고 있었는지의 여부 확인하고 Boolean 값 반환
- target : 이벤트가 발생한 대상을 반환
- timeStamp : 이벤트가 발생한 시간을 밀리초 단위로 반환
- type : 발생한 이벤트 이름을 반환
- which : 키보드와 관련된 이벤트 발생했을 때 키의 유니코드 값 반환

이벤트 전파
웹 요소에서 이벤트가 발생했을 때 해당 요소에서만 이벤트가 처리되는 것이 아니라 해당 요소를 감싸고 있는 부모 요소, 그리고 그 요소의 부모 요소에서도 똑같이 이벤트가 처리된다.
- 이벤트 버블링 : 이벤트가 발생한 요소에서부터 부모 요소로, 다시 그 요소의 부모 요소로 이벤트가 전달된다.
- 이벤트 캡처링 : 웹 요소에서 이벤트가 발생하면 일단 최상위 요소에서 시작해서 이벤트가 발생한 요소로 차례로 이벤트가 전파되는 방식

DOM 트리와 노드

DOM 트리에서 가지가 갈라져 나가는 부분을 노드라고 하고 DOM 트리의 시작 부분, 즉 html 노드를 나무의 뿌리에 해당하는 루트 노드라고 한다.
노드를 구성하는 원칙
- 모든 html 태그는 요소 노드가 된다.
- html 태그에서 사용하는 텍스트 내용은 자식 노드인 텍스트 노드가 된다.
- html 태그에 있는 속성은 모두 자식 노드인 속성 노드가 된다.
- 주석들은 주석 노드가 된다.
