Chapter 10

객체 중첩하기 : 객체 안에 또 다른 객체 넣을 수 있다 - 둘 이상의 객체 중첩

객체 메서드 정의하기
- 메서드 : 객체의 프로퍼티 중 객체의 동작을 지정하는 함수
- 메서드를 선언하는 방법은 일반적인 함수를 선언하는 것과 비슷
- this : 메서드에서 객체 안에 있는 프로퍼티값을 사용할 때, 현재 객체를 가리키는 예약어

객체 복사하기
- 원시 유형 자료 복사 : '값'을 복사한다. 복사한 자료의 값을 변경 -> 원래 자료의 값은 그대로
- 객체 복사 : '주소'를 복사한다. 복사한 자료의 값 변경 -> 원래 자료의 값도 바뀜

생성자 함수
- 객체마다 반복되는 프로퍼티와 메서드가 있다면 객체 틀을 미리 정의해 놓고 필요할 때마다 그 틀을 사용해서 객체를 만들 수 있다.
- 객체의 틀을 만들 때 사용하는 함수를 '생성자 함수'라고 한다.
- 생성자 함수를 사용해서 찍어 내는 객체를 '인스턴스' 또는 '인스턴스 객체'라고 부른다.

생성자 함수를 사용해 객체 정의하기
- 생성자 함수는 일반적인 함수와 같은 형식
- 함수 이름의 첫 글자는 대문자로 사용
- 함수 내부에서 this 사용

클래스를 사용해 객체 정의하기
- 자바스크립트의 클래스는 정확한 클래스 개념이 아니라 생성자 함수를 좀 더 표현하기 쉽게 바꾼, 신택틱 슈거다.

객체의 키와 값에 접근하기
- for...in 사용하기 : 객체의 키만 가져올 수 있다.
- keys(), values(), entries() 메서드 사용하기

프로토타입 : 객체 생성자 함수에 의해 생성되는 객체들이 공유하는 속성과 메소드를 저장하는 특수 개체, 자바스크립트의 상속은 프로토타입을 통해 이루어짐
생성자 함수를 선언하는 순간 자동으로 프로토타입 객체가 만들어진다.
_proto_ 프로퍼티
- 모든 객체가 가지고 있는 프로퍼티
- 인스턴스 객체에서 자신에게 연결된 프로토타입 객체를 확인할 때 사용한다.
prototype 프로퍼티
- 모든 객체가 가지고 있는 프로퍼티
- 프로토타입 객체에서 자기 자신을 확인할 때 사용
- 이 객체가 어떤 생성자 함수를 사용했는지, 어떤 프로퍼티와 메서드를 가지는 지 등의 정보 확인 가능

프로토타입 메서드 : 생성자 함수 밖에서 프로토타입을 사용해 새로운 메서드를 정의 가능
