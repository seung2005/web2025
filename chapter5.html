Chapter 5

연산자와 제어문
- switch문 : 처리할 명령어가 많을 경우 편리

두 가지 이상의 조건 체크
- OR 연산자(||) : 하나라도 true 있으면 결과값 true
- AND 연산자(&&) : 하나라도 false 있으면 결과값 false
- NOT 연산자(!) : 두 값과 정반대의 값

반복문
- 반복문은 같은 동작 여러 번 실행하기 위해 사용
- 소스 깔끔해지고 소스 짧아지는 만큼 실행도 빨라짐
for문
- 자바스크립트에서 가장 많이 사용
- for (초깃값; 조건; 증가식) {...} -> 초깃값은 처음에 한 번만 할당하고 조건 체크와 명령 실행, 증가식을 계속 반복
forEach문
- 배열의 크기가 정해져 있지 않을 경우에 사용
break문
- 종료 조건이 되기 전 반복문 빠져나와야할 때 사용
continue문
- 특정 조건이 됐을 때 실행하던 반복 문장을 더 이상 실행하지 않고 반복문의 맨 앞으로 되돌아감 -> 반복 과정 한 차례 건너뛰게 됨

return문
- 함수 안에서 실행하고 그 결과를 함수 밖에서 받아 처리해야 할 경우도 많다
- 함수의 실행 결과를 함수를 실행한 시점으로 넘겨주는 것을 '결괏값을 반환한다'라고 한다
- 함수를 실행한 후 결과를 반환할 때는 예약어 return 다음에 넘겨줄 값이나 변수 지정

함수 선언 & 실행
- function 이라는 예약어 사용해서 함수 선언
- 매개변수 : 함수 선언할 때 외부에서 값을 받는 변수
- 인수 : 매개변수가 있는 함수 실행할 때, 매개변수로 값을 넘겨주는 변수

스코프 : 선언한 변수의 적용 범위
- var 키워드 사용한 변수 : 함수 레벨 스코프
- let, const 키워드 사용한 변수 : 블록 레벨 스코프

자바스크립트 변수, 이렇게 사용하세요!
1. var 변수보다 let, const 변수 사용
2. 전역 변수는 최소한으로 사용
3. 객체 선언은 const 사용

익명 함수 : 변수에 할당해서 사용함
즉시 실행 함수 : 같은 함수를 여러 번 실행 가능, 한번만 사용하는 함수라면 선언과 동시에 실행 가능
화살표 함수 : => 을 사용해 함수를 좀 더 간단하게 선언
콜백 함수 : 다른 함수의 인자로 사용하는 함수
전개 구문 : 값만 꺼내서 펼쳐주는 구문, 마침표 3개를 사용해서 표현
타이머 함수 : 특정 시간이 되었을 때 함수 실행하거나 특정 시간 동안 함수를 반복하기 위해서 시간을 재는 함수
- 일정 시간마다 반복하기 setInterval(), 반복 실행 멈추기 clearInterval(), 특정 시간 이후에 한번만 실행하기 setTimeout()
